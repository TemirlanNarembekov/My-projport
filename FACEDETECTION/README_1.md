# Определение пола и возраста по лицу (UTKFace)

Система обнаруживает лица на изображениях и видео и определяет для каждого лица **пол** (бинарная классификация) и **возраст** (регрессия). Построена на основе датасета **UTKFace**.

Модель — multi-task нейросеть на базе **ResNet-50** с двумя головами (пол + возраст). Для работы с видео используется детектор лиц **InsightFace** и трекер **ByteTrack**.

---

## Содержание проекта

| Файл | Назначение |
|------|------------|
| `parser.py` | Сбор датасета: парсинг имён файлов UTKFace → `data.csv` |
| `EDA.ipynb` | Разведочный анализ данных (распределения, баланс классов, выбросы) |
| `dataset.py` | Очистка, стратифицированный split, трансформы, `Dataset`, `DataLoader` |
| `baseline.py` | Архитектура модели `MultiTaskResNet50` |
| `train.py` | Обучение модели, сохранение чекпоинтов, оценка на тесте |
| `predict.py` | Инференс на **одном изображении** (командная строка) |
| `facedetector.py` | Инференс на **видео**: детекция + трекинг + предсказание |
| `data.csv` | Таблица с путями к изображениям и метками (генерируется `parser.py`) |

## 1. Установка

### Требования
- Python 3.10+
- Желательно GPU с CUDA для обучения (на CPU обучение очень медленное). Инференс работает и на CPU.

### Установка зависимостей

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install insightface onnxruntime supervision opencv-python
pip install pandas scikit-learn Pillow matplotlib tqdm
```

> Для CPU-версии PyTorch используйте индекс `https://download.pytorch.org/whl/cpu`.
> Если есть GPU — установите `onnxruntime-gpu` вместо `onnxruntime`.

При первом запуске **InsightFace** автоматически скачает модель детектора `buffalo_l`, а **torchvision** — предобученные веса ResNet-50 (нужен интернет).

## 2. Подготовка данных

### 2.1. Скачать датасет UTKFace

Скачайте датасет UTKFace (версия «in-the-wild») и разложите изображения по папкам:

```
Dataset/
├── part1/
├── part2/
└── part3/
```

Имена файлов имеют формат `[возраст]_[пол]_[раса]_[дата].jpg`, например `25_1_0_20170116...jpg`
(пол: 0 = мужчина, 1 = женщина).

### 2.2. Собрать таблицу меток

```bash
python parser.py
```

Скрипт пройдёт по папкам `Dataset/part1..3`, распарсит метки из имён файлов, отсеет битые записи и сохранит результат в **`data.csv`**. В консоль выведется число собранных и пропущенных записей.

### 2.3. (Опционально) Анализ данных

Откройте `EDA.ipynb` в Jupyter / VS Code, чтобы посмотреть распределения возраста и пола, баланс классов и выбросы.

## 3. Обучение модели

Данные и предобработка загружаются автоматически из `dataset.py` (он читает `data.csv`, делает стратифицированный split 70/15/15 и создаёт `DataLoader`'ы).

### Запуск обучения с параметрами по умолчанию

```bash
python train.py
```

По умолчанию: 50 эпох, lr = 3e-4, batch = 64, early stopping (patience = 7), автоматический AMP при наличии GPU.

### Параметры командной строки

| Аргумент | По умолчанию | Описание |
|----------|--------------|----------|
| `--epochs` | 50 | Число эпох |
| `--patience` | 7 | Терпение early stopping |
| `--save_every` | 5 | Сохранять чекпоинт каждые N эпох |
| `--lr` | 3e-4 | Скорость обучения |
| `--weight_decay` | 1e-4 | L2-регуляризация |
| `--age_loss_weight` | 0.05 | Вес потери возраста в общем лоссе |
| `--grad_clip` | 1.0 | Ограничение нормы градиента (0 — выкл.) |
| `--checkpoint_dir` | `checkpoints` | Папка для чекпоинтов |
| `--resume` | — | Путь к чекпоинту для продолжения обучения |
| `--seed` | 42 | Random seed |
| `--no_amp` | — | Отключить mixed precision |

### Примеры

```bash
# Обучить 30 эпох с другой скоростью обучения
python train.py --epochs 30 --lr 1e-4

# Продолжить обучение с сохранённого чекпоинта
python train.py --resume checkpoints/last.pt
```

### Результаты обучения

В папке `checkpoints/` создаются:
- `best.pt` — лучшая модель (по валидационному лоссу),
- `last.pt` — последняя эпоха,
- `epoch_N.pt` — периодические срезы.

История метрик по эпохам сохраняется в `history.csv`. По завершении обучения выводятся метрики на тестовой выборке: точность по полу и MAE по возрасту.

> **Важно:** для инференса нужен файл `best.pt`. Скопируйте его из `checkpoints/` в корень проекта (рядом с `predict.py` и `facedetector.py`), либо укажите путь явно.

## 4. Инференс на одном изображении

```bash
python predict.py --checkpoint best.pt --image path/to/photo.jpg
```

Выведет предсказанные пол (с уверенностью) и возраст. Изображение должно быть **кропом лица** (как в обучающем датасете).

## 5. Инференс на видео

```bash
python facedetector.py
```

Скрипт обрабатывает видеофайл (по умолчанию имя задаётся в коде переменной `VIDEONAME`), на каждом кадре обнаруживает лица, ведёт их трекинг с присвоением ID и предсказывает пол/возраст. Результат:
- показывается в окне (выход по клавише **`q`**),
- сохраняется в файл `inference<имя_видео>.mp4`.

### Настройка (переменные в начале `facedetector.py`)

| Переменная | Назначение |
|------------|------------|
| `VIDEONAME` | Путь к входному видео |
| `MARGIN_W`, `MARGIN_H` | Расширение области лица по ширине/высоте (доля от размера лица) |
| `INFER_EVERY` | Пересчитывать предсказание раз в N кадров |
| `lost_track_buffer` | Сколько кадров хранить трек после исчезновения лица |

Предсказания **агрегируются по треку**: возраст усредняется, пол определяется голосованием по кадрам — это делает результат устойчивым к шуму и кратковременным перекрытиям лиц.

> Для запуска нужен файл `best.pt` в корне проекта.

## 6. Типовой сценарий (полный цикл) - инструкция по использованию:

```bash
# 1. Собрать датасет в таблицу
python parser.py

# 2. Обучить модель
python train.py

# 3. Скопировать лучшую модель в корень
cp checkpoints/best.pt best.pt

# 4a. Проверить на одном фото
python predict.py --checkpoint best.pt --image test.jpg

# 4b. Запустить на видео
python facedetector.py
```

## Ограничения

- **Пожилые люди (60+)** предсказываются менее точно — в UTKFace мало таких примеров.
- **Плотные сцены** (лица вплотную, перекрытие рамок) могут приводить к ошибкам пола; частично компенсируется голосованием по треку.
- Модель обучена на «широких» in-the-wild изображениях, поэтому при инференсе область лица расширяется (`MARGIN_W/H`), чтобы приблизить кроп к обучающим данным.
